# Data Reduction and CMD Construction for ASTR 3070

### Kaggle Instructions

Create an account and verify your phone number - this is the only way to allow internet access through the editor

Next, click Create -> Import Notebook -> GitHub: https://github.com/pirgalim/ASTR3070-public

This will take a little bit to load, once finished click to edit the notebook

Install the required packages, click Add-Ons -> Install Dependencies then paste and run:
- pip install twirl
- pip install photutils

To add the images, go to Input -> Upload -> New Dataset


### VSCode Instructions

Create venv with Python version 3.11 or 3.10 (certain packages are not yet supported in higher versions)

Run 'pip install -r requirments.txt' in the venv terminal
